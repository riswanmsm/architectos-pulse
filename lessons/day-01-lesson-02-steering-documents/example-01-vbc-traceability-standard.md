# Steering Example 01: Global VBC Cross-Artifact Traceability Standard

## 1. Convention & Standard to Enforce
Every module, service class, and endpoint generated by Kiro MUST include explicit **Verified Blueprint Coverage (`VBC-01` through `VBC-07`)** traceability tags (`FR-X`, `COMP-X`, `ENT-X`, `TEST-X`) in its docstring and metadata so that `BlueprintVerifier` achieves $\ge 94.0\%$ coverage.

## 2. Intent & Context
When multiple AI specialists or developers iterate on a repository, code rapidly drifts from `.kiro/specs/requirements.md`. Requiring explicit `FR-X`, `COMP-X`, `ENT-X`, and `TEST-X` identifiers allows `BlueprintVerifier` (`verifier.py`) and Jev System-1 hooks to deterministically verify 100% implementation and test alignment in under 15ms.

## 3. Code Comparison

### ❌ Non-Compliant (No Traceability to `.kiro/specs/`)
```python
def generate_blueprint(idea: str) -> dict:
    """Generates an architecture blueprint."""
    return run_pipeline(idea)
```

### ✅ Compliant (Full VBC-01 & VBC-02 Traceability)
```python
def generate_blueprint(idea: str) -> dict:
    """
    Implements FR-101, FR-201 | Component: COMP-COORDINATOR | Entity: ENT-BLUEPRINT-SESSION | Verified by: TEST-201.
    Orchestrates the 8-specialist committee and verifies VBC >= 94.0%.
    """
    return run_pipeline(idea)
```
